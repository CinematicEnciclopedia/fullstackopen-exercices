Repositori d'entrega d'exercicis del curs [Full Stack Open](https://fullstackopen.com) (Universitat de Hèlsinki).

- Usuari del curs: Dani (CinematicEnciclopedia).
- Estat: **Parts 0–6 fetes**.

## Convencions

- Els exercicis s'entreguen via GitHub i es marquen com a fets al sistema d'entrega (https://studies.cs.helsinki.fi/stats/courses/fullstackopen).
- S'entreguen una part a la vegada; un cop enviada una part, no es poden afegir exercicis omesos.
- Els exercicis 0.1–0.3 són només lectura de tutorials MDN i no tenen lliurament.
