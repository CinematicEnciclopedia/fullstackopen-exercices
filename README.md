# Full Stack Open — Entrega d'exercicis

Repositori d'entrega d'exercicis del curs [Full Stack Open](https://fullstackopen.com) (Universitat de Hèlsinki).

- Usuari del curs: Dani (CinematicEnciclopedia).
- Estat: **Part 0, Part 1 i Part 2 fetes** (0.1–0.6, 1.1–1.14, 2.1–2.20).

## Estructura

```text
part0/
 0.4.md   Diagrama: nova nota (aplicació tradicional)
 0.5.md   Diagrama: accés a la SPA
 0.6.md   Diagrama: nova nota a la SPA

part1/
  courseinfo   (1.1–1.5 / 2.1–2.5 ja migrat a part2)
  unicafe      (1.6–1.11: recompte d'estats)
  anecdotes    (1.12–1.14: votacions)

part2/
  courseinfo   (2.1–2.5: Course component, reduir, mòdul separat)
  phonebook    (2.6–2.17: formulari, filtre, axios + json-server, CRUD)
  countries    (2.18–2.20: API restcountries + meteorologia)
```

## Convencions

- Els exercicis s'entreguen via GitHub i es marquen com a fets al sistema d'entrega (https://studies.cs.helsinki.fi/stats/courses/fullstackopen).
- S'entreguen una part a la vegada; un cop enviada una part, no es poden afegir exercicis omesos.
- Els exercicis 0.1–0.3 són només lectura de tutorials MDN i no tenen lliurament.
