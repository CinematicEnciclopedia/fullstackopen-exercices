# 0.4 Nova nota (aplicació tradicional)

Diagrama de la cadena d'esdeveniments quan l'usuari crea una nova nota a `https://studies.cs.helsinki.fi/exampleapp/notes`, escrivint al camp de text i fent clic al botó `Save`.

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note right of browser: L'usuari escriu una nota i fa clic al botó Save
    browser->>server: POST https://studies.cs.helsinki.fi/exampleapp/new_note
    activate server
    Note left of server: El servidor afegeix la nota a l'array notes i respon amb una redirecció 302
    server-->>browser: 302 Found · Location: /notes
    deactivate server

    Note right of browser: El navegador segueix la redirecció i torna a carregar la pàgina
    browser->>server: GET https://studies.cs.helsinki.fi/exampleapp/notes
    activate server
    server-->>browser: HTML document
    deactivate server

    browser->>server: GET https://studies.cs.helsinki.fi/exampleapp/main.css
    activate server
    server-->>browser: the css file
    deactivate server

    browser->>server: GET https://studies.cs.helsinki.fi/exampleapp/main.js
    activate server
    server-->>browser: the JavaScript file
    deactivate server

    Note right of browser: El navegador executa el codi JavaScript, que obté les notes en format JSON

    browser->>server: GET https://studies.cs.helsinki.fi/exampleapp/data.json
    activate server
    server-->>browser: [{ "content": "nova nota", "date": "..." }, ...]
    deactivate server

    Note right of browser: El navegador executa la funció de callback que renderitza les notes
```
