# 0.6 Nova nota a la versió SPA

Situació en què l'usuari crea una nova nota utilitzant la versió d'aplicació d'una sola pàgina.

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note right of browser: L'usuari escriu una nota i fa clic al botó Save. La SPA no recarrega la pàgina

    Note right of browser: El codi JavaScript crea la nova nota localment (DOM-API) i l'afegeix a la llista renderitzada
    browser->>server: POST https://studies.cs.helsinki.fi/exampleapp/new_note_spa
    activate server
    Note left of server: El servidor afegeix la nota a l'array notes amb content i date
    server-->>browser: 201 Created
    deactivate server

    Note right of browser: El servidor no sol·licita una redirecció; el navegador roman a la mateixa pàgina i no envia més sol·licituds HTTP
```
